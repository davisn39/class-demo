# Class Demo

This project is a simple static HTML demo site.

## Files
- [Index.html](Index.html) contains the page content.

## Run it locally
Open [Index.html](Index.html) in a browser, or serve the folder with:

```bash
cd /workspaces/class-demo
python3 -m http.server 8000
```

Then visit http://localhost:8000/ in your browser.
